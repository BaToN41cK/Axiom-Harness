# DateTime

Работа с текущим временем, часовыми поясами и арифметикой дат.

## Инструменты

### `current_time`

Возвращает дату, время, день недели и unix-время. Можно указать часовой пояс.

| Параметр | Тип | Обязателен | Описание |
|----------|-----|:----------:|----------|
| `timezone` | string | нет | IANA-имя пояса, например `Europe/Moscow`, `Asia/Tokyo`, `utc`. Пусто — локальное время |

Если задан удалённый пояс, дополнительно печатается локальное время для сравнения.

### `date_diff`

Считает количество дней между двумя датами.

| Параметр | Тип | Обязателен | Описание |
|----------|-----|:----------:|----------|
| `a` | string | да | Начальная дата, `YYYY-MM-DD` или `today` |
| `b` | string | да | Конечная дата, `YYYY-MM-DD` или `today` |

Положительный результат означает, что `b` позже `a`.

## Примеры

```
current_time timezone="Europe/Moscow"
  → Date: 2026-09-25 (Пятница)
    Time: 19:07:16
    Zone: Europe/Moscow (UTC offset +0300)

date_diff a="2026-01-01" b="today"
  → 2026-01-01 → 2026-09-25: 267 day(s)
```
