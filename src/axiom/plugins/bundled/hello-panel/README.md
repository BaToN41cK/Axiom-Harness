# hello-panel

Пример UI-плагина для AXIOM (W3.1).

Объявляет два расширения интерфейса в `manifest.json`:

- **панель** `hello` — рендерится хостом в изолированном iframe;
- **команда** `hello-greet` — команда, которую хост выполняет по запросу.

Плагин запрашивает только scope `ui` и не получает доступа к `fs`, `net` или
`clipboard`. Код плагина не имеет прямого доступа к DOM AXIOM и IPC — только к
типизированному протоколу `axiom.core.plugin_host`.
