# Calculator

Безопасный калькулятор арифметических выражений. Разбор идёт по AST — **никакого `eval`**, поэтому произвольный код выполнить нельзя.

## Что умеет

- Арифметика: `+  -  *  /  //  %  **`
- Скобки и приоритет операций
- Унарный плюс и минус
- Функции: `sqrt`, `sin`, `cos`, `tan`, `asin`, `acos`, `atan`, `log`, `log10`, `log2`, `floor`, `ceil`, `abs`, `round`, `min`, `max`, `pow`, `exp`
- Константы: `pi`, `e`, `tau`

## Инструмент

### `calculate`

Вычисляет одно арифметическое выражение и возвращает результат.

| Параметр | Тип | Обязателен | Описание |
|----------|-----|:----------:|----------|
| `expression` | string | да | Выражение, например `2 + 3 * sqrt(16)` |

Ограничение длины выражения — 200 символов.

## Примеры

```
2 + 3 * sqrt(16)      → 14
(1 + 2) ** 3          → 27
log2(1024)            → 10
sin(pi / 2)           → 1
```

## Безопасность

Доступ к переменным, атрибутам и импортам запрещён. Разрешена только числовая математика из белого списка выше — любой другой синтаксис отклоняется с ошибкой.
