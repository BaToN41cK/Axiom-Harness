# TextTools

Утилиты для работы с текстом: статистика, трансформации и кодирование.

## Инструменты

### `text_stats`

Показывает статистику текста: количество символов, слов, строк и байтов.

| Параметр | Тип | Обязателен | Описание |
|----------|-----|:----------:|----------|
| `text` | string | да | Произвольный текст |

Возвращает:
- Characters — количество символов
- Words — количество слов (через пробелы)
- Lines — количество строк
- Bytes (UTF-8) — размер в байтах

### `text_transform`

Преобразует текст одной из операций.

| Параметр | Тип | Обязателен | Описание |
|----------|-----|:----------:|----------|
| `text` | string | да | Исходный текст |
| `operation` | string | да | Операция (см. ниже) |

**Доступные операции:**
- `lower` — в нижний регистр
- `upper` — в верхний регистр
- `title` — Первая Буква Каждого Слова Заглавная
- `capitalize` — Только первая буква заглавная
- `slug` — превращает текст в url-совместимый слаг (пробелы → дефисы, всё в нижний регистр)
- `reverse` — переворачивает текст задом наперёд
- `strip` — убирает пробелы по краям
- `collapse` — схлопывает множественные пробелы в один

### `encode_text`

Кодирует или декодирует текст.

| Параметр | Тип | Обязателен | Описание |
|----------|-----|:----------:|----------|
| `text` | string | да | Текст для кодирования/декодирования (до 50 000 символов) |
| `codec` | string | да | Кодек (см. ниже), с префиксом `decode:` для декодирования |

**Доступные кодеки:**
- `base64` — стандартный base64
- `base64url` — URL-safe base64 (без padding `=`)
- `hex` — шестнадцатеричная кодировка
- `url` — URL percent-encoding
- `html` — HTML entity escape

Для декодирования добавь префикс `decode:`, например `decode:base64`.

## Примеры

```
text_stats text="hello world"
  → Characters: 11
    Words: 2
    Lines: 1
    Bytes (UTF-8): 11

text_transform text="AXIOM Terminal" operation="slug"
  → axiom-terminal

encode_text text="hello" codec="base64"
  → aGVsbG8=

encode_text text="aGVsbG8=" codec="decode:base64"
  → hello
```
