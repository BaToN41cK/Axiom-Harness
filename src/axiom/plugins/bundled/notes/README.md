# Notes

Персональный блокнот внутри AXIOM. Каждая заметка получает временную метку и опциональный тег. Заметки хранятся в `~/.axiom/notes/notes.md`.

## Инструменты

### `note_add`

Добавить заметку в конец блокнота.

| Параметр | Тип | Обязателен | Описание |
|----------|-----|:----------:|----------|
| `text` | string | да | Текст заметки (до 4000 символов) |
| `tag` | string | нет | Опциональный тег, например `idea` или `todo` |

Тег добавляется как `#tag` после timestamp. Максимальная длина заметки — 4000 символов.

### `note_list`

Показать заметки (новые — первыми). Можно отфильтровать по подстроке или тегу.

| Параметр | Тип | Обязателен | Описание |
|----------|-----|:----------:|----------|
| `filter` | string | нет | Подстрока или `#tag` для поиска |

Если фильтр не задан, показываются все заметки. Если блокнота ещё нет, вернёт `(no notes yet)`.

## Примеры

```
note_add text="Изучить async/await" tag="todo"
  → Note saved #todo.

note_list filter="todo"
  → - [2026-09-25 19:15] #todo Изучить async/await
    - [2026-09-22 14:30] #todo Проверить логи сервера
```

## Формат хранения

Каждая заметка — одна строка в формате:
```
- [YYYY-MM-DD HH:MM] #tag текст заметки
```

Файл живёт по пути `~/.axiom/notes/notes.md` и его можно открыть в любом markdown-редакторе.
